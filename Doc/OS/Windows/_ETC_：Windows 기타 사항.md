## 시작하기

&nbsp; 윈도우 설치 USB 만들고 연결합니다.

&nbsp; 해당 기기의 바이오스에 진입하여 부팅 우선도를 해당 USB 로 지정해주세요.

### 시작과 작업표시줄 설정

#### 작업표시줄

&nbsp; 작업표시줄에 우클릭을 하여 `작업표시줄 설정` 으로 진입하여 작업표시줄을 커스텀 할 수 있습니다.

#### 위젯

&nbsp; 윈도우즈 11 에선 좌측 화면 슬라이드터치 나 <kbd>Win</kbd> + <kbd>W</kbd> 명령어로 위젯 화면을 킬 수 있습니다. 다만 이것이 환경 자원을 소모하고 작업 중 방해가 될 수 있습니다.

&nbsp; 다음의 방법으로 Widgets 항목이 작동하지 않게 만들거나 반대로 작동하게 만들 수 있습니다.

-   `작업 표시줄 설정` 에서 항목 목록 중, 위젯 항목 토글을 '끔'으로 변경

-   <kbd>Win</kbd> + <kbd>X</kbd> 입력 (또는, 작업표시줄 윈도우즈 로고 우클릭) 후 터미널(관리자) 기동. 다음의 명령어로 Widget 관련 패키지를 제거합니다.

    ```bash
    # winget 패키지 관리자가 있을 경우
    winget uninstall "Windows Web Experience Pack"
    # 내 계정에서만 삭제하려고 할 경우
    Get-AppxPackage *WebExperience* | Remove-AppxPackage
    # 모든 계정에서 싹 밀어버리려고 할 경우
    Get-AppxPackage -AllUsers *WebExperience* | Remove-AppxPackage -AllUsers
    ```

    몇 초 후 아무 메시지 없이 다음 입력 줄로 넘어가지면 정상적으로 제거된 것입니다.

#### 시작

&nbsp; 작업표시줄의 윈도우 로고에 우클릭 -> `설정` -> `개인 설정` -> `시작` 항목에서 시작 팝업 박스의 설정을 할 수 있습니다.

&nbsp; `시작` -> `폴더` 항목에서 시작 화면 하단에 숏컷 경로를 넣을 수 있습니다. `설정` 과 `파일탐색기` 숏컷을 넣어두면 편합니다.

&nbsp; 시작 검색창에 `제어판` 을 검색 후, 시작 화면에 고정해두면 편합니다.

#### 시작 앱 설정

&nbsp; Windows OS 가 시작될 때, 자동으로 실행되는 프로그램들을 미리 지정해두면 편합니다. (예시: 스티커 메모)

-   탐색기 주소창에
    -   shell:appsfolder 입력하여 앱들의 바로가기 폴더에 접근가능
    -   shell:startup 입력하여 바로가기 폴더를 생성하면 시작프로그램으로 기동합니다.

#### 윈도우 터미널 단축키 설정

&nbsp; 작업표시줄 윈도우즈 로고 우클릭으로도 터미널에 접근 가능합니다. 하지만 마우스 동작이 귀찮을 때, 단축키 접근이 편합니다.

-   시작에서 powershell or cmd 중 선호하는 터미널 검색
-   우클릭 "파일 위치 열기"
-   해당 파일에 우클릭->추가옵션표시->바로가기 파일을 두 개를 만들어줍니다.
-   첫번째 바로가기 파일에<br/>`-⇀`우클릭 속성 `-⇀` 바로가기 키를 클릭하고 단축키 Crtl + Alt + T 를 입력합니다.
-   두번째 바로가기 파일에<br/>`-⇀`우클릭 속성 `-⇀` 바로가기 키를 클릭하고 단축키 Crtl + Alt + Shift + T 를 입력합니다.<br/>`-⇀`우클릭 속성 `-⇀` 고급에 관리자 권한으로 실행 체크합니다.
-   파워쉘이 켜지면 우클릭 `-⇀` 속성의 편집옵션 항목에서 Ctrl+Shift+C/V 복사 붙여넣기 항목에 체크해주면 복사 붙여넣기를 쉽게 할 수 있습니다.

### One drive 체크

&nbsp; 의도하지 않은 공유가 일어나지 않도록 사전에 One drive 설정을 조정해야 합니다.

#### OneDrive 단순 백업 해제

-   시작 메뉴에서 검색창에 OneDrive 검색 후 선택
-   탐색기 창으로 팝업되는 OneDrive 폴더에 상단 경로 쪽에 OneDrive 클릭
-   OneDrive 메뉴 설정(톱니바퀴 모양) 클릭
-   `우측 탭 동기화 및 백업 > 백업 관리` 에서 모든 파일 해제
-   `우측 탭 계정 > 폴더 선택` 에서 백업할 폴더만 선택

#### OneDrive 경로 레지스트리 편집

&nbsp; 바탕화면, 유저, 사진 폴더가 OneDrive 폴더로 연결되는 경로를 수정합니다.

-   `Win + R` 을 눌러 실행 창을 열고, regedit를 입력하여 레지스트리 편집기를 실행합니다.
-   `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders` 로 이동합니다.
-   `Desktop`, `Personal`, `My Pictures` 항목을 찾아 값 데이터를 각각

    -   `%USERPROFILE%\Desktop`
    -   `%USERPROFILE%\Documents`
    -   `%USERPROFILE%\Pictures`

    로 수정합니다.

#### OneDrive 자동 실행 방지

&nbsp; OneDrive가 자동으로 실행되지 않도록 설정하여 불필요한 동기화를 방지할 수 있습니다.

-   `Ctrl + Shift + del` 를 눌러 작업 관리자를 엽니다.
-   상단의 `시작 프로그램` 탭을 클릭합니다.
-   목록에서 **'Microsoft OneDrive'**를 찾아 우클릭한 후, **'사용 안 함'**을 선택합니다.

### 속도 및 보안성 개선

-   `설정 > 네트워크 및 인터넷 > 프록시` 에서 `자동으로 설정 검색` 끄기
-   `설정 > 개인 설정 > 시작` 에서 `팁, 바로가기, 새 앱 등에 대한 권장 사항 표시` 끄기
-   `설정 > 개인 정보 및 보안 > 일반` 에서
    -   `내 광고 ID를 사용하여 앱에서 개인 설정된 광고를 표시하도록 허용` 끄기
    -   `Windows에서 앱 시작을 추적해서 시작 및 검색 결과를 개선할 수 있게 해 주세요.` 끄기 (대신 명령어 목록 같은 것이 남지 않게되서 불편할 수는 있습니다)
    -   `앱 설정 시 제안되는 내용 표시` 끄기

### 임시 파일 정리 및 최적화

&nbsp; 윈도우즈 11 부터는 임시 저장파일을 OS 에서 처리해줍니다. 

-   설정 ➔ 시스템 ➔ 저장소 ➔ 저장공간센스 옵션 활성화
-   설정 ➔ 시스템 ➔ 저장소 ➔ 추천 정리 ➔ 고급 옵션 보기
-   설정 ➔ 시스템 ➔ 저장소 ➔ 고급 저장소 설정 ➔ 드라이브 최적화

### 설치 파일 정리

-   `Windows` 폴더와 같이 최상단에 있는 `Program files` 는 특별히 관리되는 폴더입니다. 이 곳으로 파일을 몰아서 정리할 경우 가끔 권한 문제로 업데이트나 호출이 안될 때가 있습니다.
-   `Apps` 라는 폴더나 `Applications`, `Program apps`, `Program files(user)` 같은 개인용 묶음 폴더를 만들어 마음대로 관리하면서도 직관성을 유지해줄 수 있습니다. 

### 안전모드 부팅

&nbsp; `설정` -> `복구` -> `고급 시작 옵션` 항목의 [지금 다시 시작] 버튼을 클릭합니다.

&nbsp; Windows OS 의 옵션 선택 화면으로 다시 시작되면 [문제 해결] 버튼을 클릭합니다.

&nbsp; `고급 옵션` -> `시작 설정` -> `다시 시작` 후 다시 시작되고 나면 옵션 목록이 나옵니다.

&nbsp; 옵션 목록에서 안전모드에 해당하는 키를 누르면 됩니다.

### 프린터 대기열 오류 해결방법

-   [관련 링크](https://support.hp.com/kr-ko/document/c04746618)

&nbsp; 프린터 스풀러 기능에 문제가 발생하였을 경우 프린터 인쇄 대기열에 문서가 계속 쌓일 뿐 아니라 취소 또한 불가능해집니다.

&nbsp; 이 경우에 직접 강제로 해당 로그를 지워주면 정상적으로 작동합니다.

-   1 : 명령프롬프트 터미널 관리자권한으로 실행하기

    -   `Win + R` -> `cmd 입력` -> `ctrl + shift + enter`(관리자 권한 실행)

-   2 : 프린트 스풀러 서비스 강제 중지

    -   `net stop spooler` 입력

-   3 : 프린트 파이프라인 프로세스 강제 종료

    -   `taskkill /f /im printfilterpipelinesvc.exe`

-   3+ : 스풀러는 종료되었지만 혹시 종료가 되지 않았다면 강제종료

    -   `taskkill /f /im splwow64.exe` & `taskkill /f /im spoolsv.exe`

-   4 : 남아 있는 .SPL, .SHD, .TMP 파일 전부 삭제

    -   `del /f /q C:\Windows\System32\spool\PRINTERS\*.*`

-   5 : 프린트 스풀러 서비스 재실행
    -   `net start spooler`

&nbsp; 이제 목록이 깔끔하게 사라져 다시 인쇄 작업이 가능할 것 입니다.

-   3번째 부팅 시 자동 복구 준비 메시지가 뜨며 고급 복구 환경으로 진입합니다.
-   `문제 해결` > `고급 옵션` > `시작 설정` > `다시 시작` 을 순서대로 선택합니다.

### Windows OS 찌꺼기 정리

#### 기타 파일 정리

-   `Revo Uninstaller`, `CCleaner`, `auslogics disk defrag` 와 같은 검증된 최적화 프로그램에 포함된 디스크 및 레지스트리 클리너 기능을 사용합니다.

-   관리자 권한 탐색기 `explorer.exe` 로 직접 찾아서 제거
    -   기존의 `explorer.exe`(Windows 탐색기) 폴더 작업은 창을 닫아주세요.
    -   Windows의 파일 탐색기(File Explorer, explorer.exe)는 일반적으로 시스템 셸(Shell)로 작동하며 로그인한 사용자 권한으로 실행됩니다. 하지만 시스템 파일 수정이나 권한이 제한된 폴더(예: C:\Windows\System32)에 접근할 때는 관리자 권한이 필요합니다. 관리자 권한을 부여하기 위하여 작업 관리자를 다음의 방법으로 열어주세요. `Ctrl + Shift + Esc` 키를 동시에 누르거나, 작업 표시줄에 마우스 오른쪽 버튼을 클릭하여 작업 관리자를 실행해주세요.
    -   작업 관리자 상단 메뉴에서 **파일(File)**을 클릭한 후, **새 작업 실행(Run new task)**을 선택합니다.
    -   `explorer.exe` 를 입력하고 <u><b>관리자 권한으로 이 작업 실행(Create this task with administrative privileges)</u></b> 옵션을 체크합니다.
    -   확인을 클릭하고 사용자 계정 컨트롤(UAC) 창이 뜨면 예를 클릭하여 관리자 권한을 부여합니다.

#### 임시 데이터 정리

-   `Win + R` 입력으로 실행창 키고
    -   실행창에 `temp` 입력. 내부 범용 임시파일 삭제
    -   실행창에 `%temp%` 입력. 내부 Windows 앱 임시파일 삭제
    -   실행창에 `%localappdata%\nvidia` 입력. DXCache와 GLCache 폴더 내부 NVIDIA 그래픽 캐시파일 삭제
    -   실행창에 `wsreset.exe` 입력. 마이크로소프트 스토어 캐시파일 삭제(그냥 마이크로소프트 스토어가 켜지면 정상 동작한 것)
    -   실행창에 `cleanmgr` 입력. 나오는 창의 체크박스를 선택하여 디스크 파일 정리
        -   `시스템 파일 정리`를 클릭하여 더 많은 옵션을 표시하고 정리할 수 있습니다.
            -   Windows 업데이트 정리 (이전 업데이트 파일)
            -   임시 Windows 설치 파일
            -   Windows Defender 바이러스 백신
            -   임시 파일
            -   휴지통

#### Windows OS 이미지 손상 관리

-   관리자 권한으로 터미널창을 띄워 이미지 기반 손상 관리를 시도합니다.

#### 레지스트리 정리

&nbsp; 레지스트리는 Windows의 핵심 설정 데이터베이스이므로, 수동으로 삭제하거나 검증되지 않은 도구를 사용하는 것은 시스템 오류를 유발할 수 있어 매우 위험합니다. 대부분의 경우 레지스트리 크기는 무시할 만하며, 정리해도 체감 속도 향상은 거의 없습니다. (⚠️ 경고: 레지스트리 정리는 시스템 불안정을 초래할 수 있으므로, 반드시 백업 후 진행하고, 가능하다면 전문 프로그램을 통해 진행하는 것이 좋습니다.)

#### 레지스트리 백업

-   regedit을 실행하고 파일(File) > **내보내기(Export)**를 선택하여 전체 레지스트리를 백업 파일(.reg 확장자)로 저장합니다. (필수)

### XBOX Gamebar

&nbsp; XBOX Gamebar overlay 를 제거하고 나서도 레지스트리 데이터 때문에 없는 오버레이 프로그램을 실행하려고 할 수 있습니다.

-   방법1.  Windows 설정 비활성화
    -   <kbd>Win</kbd> + <kbd>I</kbd> 입력으로 설정으로 갑니다.
    -   게임 > Xbox Game Bar 메뉴로 이동합니다. 
    -   항목을 비활성화 시킵니다.

-   방법2-1. 레지스트리 데이터 수정
    -   <kbd>Win</kbd> + <kbd>R</kbd> 입력으로 실행창을 킵니다.
    -   regedit 을 입력하여 레지스트리 편집으로 이동합니다.
    -   `HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\GameDVR` 경로로 이동합니다.
    -   오른쪽 목록에서 AppCaptureEnabled 항목을 찾아 더블 클릭하여 접근한 뒤에 숫자값을 0 으로 수정해줍니다. (없을 경우에는 마우스 우클릭 -> DWORD(32비트) 값 생성 후 이름을 AppCaptureEnabled로 직접 만든 후 값을 0 으로 해주면 됩니다)
    -   `HKEY_CURRENT_USER\System\GameConfigStore` 경로로 이동합니다.
    -   GameDVR_Enabled 항목의 값 데이터를 0으로 수정합니다.
    -   그 후, 컴퓨터를 재부팅합니다.

-   방법2-2. 레지스트리 명령어로 한 번에 적용하기
    -   <kbd>Win</kbd> + <kbd>X</kbd> 키보드 입력으로 터미널을 실행합니다.
    -   아래 명령어를 입력합니다.
        ```bash
        reg add "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\GameDVR" /v AppCaptureEnabled /t REG_DWORD /d 0 /f
        reg add "HKCU\System\GameConfigStore" /v GameDVR_Enabled /t REG_DWORD /d 0 /f
        ```
    -   그 후, 컴퓨터를 재부팅합니다.

### 윈도우 원격 데스크탑

&nbsp; 두 Windows OS 기기가 wi-fi 연결 지원, 또는 미라캐스트 통신 지원을 할 경우 원격 데스크탑 사용이 가능합니다.

#### (1) 원격화면을 받는 수신 기기 설정

-   기능 설치 확인
   	-   `설정` -> `시스템` -> `선택적 기능` -> `선택적 기능 보기 또는 편집` 항목의 <kbd>기능 보기</kbd> 버튼 클릭 
   	-   기능 보기 중, "무선 디스플레이" 를 찾거나 검색하여 체크박스를 활성화하여야함.
-   프로젝션 설정 이동
   	-   `설정` -> `시스템` -> `이 PC에 화면 표시` 로 이동
-   수신 권한 허용
   	-   옵션을 다음과 같이 변경하여 수신을 활성화합니다.
       	-   <u><b>첫 번째 항목:</b></u> '안전한 네트워크에서는 어디서나 사용 가능' 또는 '어디서나 사용 가능'으로 변경합니다. (이 설정을 켜야 비활성화되어 있던 아래 옵션들이 풀립니다.)
       	-   <u><b>이 PC에 연결 요청:</b></u>  기본값인 '처음에만'으로 두셔도 무방합니다.
       	-   <u><b>연결하는 데 PIN 필요:</b></u>  보안을 위해 '처음에만' 또는 편리함을 위해 '안함'을 선택합니다.
-   `이 PC에 화면표시` 옵션 창의 상단에 `무선 디스플레이 앱을 시작하여 이 PC 화면에 표시` 를 클릭하면 원격화면 출력창이 실행되며 대기합니다.

#### (2) 원격화면을 보내는 발신 기기 설정

-   캐스트(Cast) 메뉴 열기
    -   <kbd>⊞ Win</kbd> + <kbd>K</kbd> 단축키를 입력하면 캐스트 연결 창이 나타납니다.

-   수신 기기 선택 및 연결
    -   검색된 무선 디스플레이 목록에서 본인의 수신받을 기기를 찾아서 선택합니다.

-   펜/터치 권한 허용
    -   데스크탑의 캐스트 연결창에서 `이 디바이스의 마우스, 키보드, 터치 및 펜 입력 허용` 이 체크가 되어야 수신기기 쪽의 원격 입력이 전달됩니다.

### KMS(키 관리 서비스)를 통한 정품 인증 방법

-   [Microsoft 공식 문서](https://learn.microsoft.com/ko-kr/windows-server/get-started/kms-client-activation-keys?tabs=windows1110ltsc%2Cwindows81%2Cserver2025%2Cversion1803#install-a-product-key)

#### 방화벽 포트 확인

&nbsp; 개인 방화벽이나 보안 프로그램이 KMS 통신에 사용되는 TCP 1688 포트를 차단하고 있을 수 있습니다. 해당 포트의 아웃바운드(외부 연결)를 허용하는지 확인해 보세요.

#### 시스템 시간 및 날짜 확인

KMS 인증은 클라이언트와 호스트 서버 간의 시간 동기화가 매우 중요합니다.

관리자 권한의 명령 프롬프트에서 다음 명령어를 실행하여 시간을 동기화해주세요.

```bash
w32tm /resync
```

#### KMS 서버 주소 확인

&nbsp; 설정한 KMS 서버 주소가 작동하지 않거나 접속이 불안정할 수 있습니다. 공개된 다른 KMS 서버 주소를 검색하여 변경 후 다시 시도해 보세요

&nbsp; 관리자 권한의 명령 프롬프트에서 다음의 명령어로 혹시 모르니 이전 KMS 서버 정보를 지워주세요.

```bash
slmgr /ckms
```

&nbsp; KMS 서버 주소를 찾아 설정합니다. 다음과 같은 리스트들이 있으나 매번 달라집니다.

-   kms.03k.org
-   kms.loli.best
-   kms.moeyuuko.com
-   kms.digiboy.ir

&nbsp; KMS 통신은 기본적으로 TCP 포트 1688을 사용합니다. 이 포트가 열려 있는지 확인하는 것이 중요합니다. 파워쉘에서 다음의 명령어로 핑(Ping) 테스트를 진행하여 서버 상태를 확인할 수 있습니다.

```bash
# Test-NetConnection -ComputerName 『KMS_SERVER_NAME』 -Port 『PORT_NUMBER』
Test-NetConnection -ComputerName kms.03k.org -Port 1688
```

ComputerName(KMS 서버 컴퓨터의 이름) 이 입력한 값과 맞는 지, RemoteAddress(KMS IP 주소) 값이 이상하지 않은지, RemotePort(KMS 통신 TCP 포트 번호) 가 1688 인지, SourceAddress(요청한 본인의 IP) 가 올바른지 확인해주세요.
마지막 값이 가장 중요한 부분으로 TcpTestSucceeded(통신 성공 여부) 가 True 인지를 확인해주세요.

&nbsp; 관리자 권한의 명령 프롬프트에서 다음의 명령어로 KMS 서버 주소를 설정합니다.

```bash
slmgr /skms 『KMS_SERVER_NAME』
```
