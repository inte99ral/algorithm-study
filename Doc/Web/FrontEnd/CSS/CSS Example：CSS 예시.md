# CSS Example：CSS 예시

<img src="." alt="." width="980" style="width: 980px" />

깃허브 md 에선 style 이 무시되기 때문에 width 에 숫자를 기입해야합니다. GitHub 스타일을 재현할 때 많이 쓰는 폭은 다음과 같습니다.

-   980px — GitHub CSS 기본값을 그대로 따르는 경우 (가장 일반적)

-   900px~920px — 사이드바 열림 상태나 문서 콘텐츠 최적화를 위해 실측값 반영

-   896px - 전체 20px 정도의 틈을 놔두는 크기

-   680px — 모바일/작은 화면 환경에서 사용
