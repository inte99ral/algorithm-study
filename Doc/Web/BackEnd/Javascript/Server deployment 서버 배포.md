# Server Deployment：서버 배포

&nbsp; 외부 인터넷망과 내부를 연결하여 서버를 작동 시키기 위해서 먼저 공유기 설정을 확인해야 합니다.

&nbsp; 과거의 IPv4 환경에서는 공인 IP 주소가 부족했기 때문에 가정 내의 여러 기기가 하나의 공인 IP 주소만 공유하기 위해 NAT (Network Address Translation) 라는 기술을 사용해야 했습니다. 포트 포워딩은 이 때 IPv4 의 NAT 벽을 뚫고 외부에서 특정 내부 기기로 접속을 유도하기 위해서 필요한 설정입니다.

&nbsp; 현대의 IPv6 는 주소 공간이 매우 넓어 가정 내의 모든 기기가 고유한 공인 IP 주소를 가질 수 있습니다. NAT가 필요 없고 외부에서 특정 기기에 직접 접근하는 것이 기본적으로 가능합니다. IPv6 환경에서는 NAT를 우회하는 포트 포워딩 개념 자체가 필요 없어지거나, 그 역할이 방화벽(Firewall) 설정으로 대체됩니다.

&nbsp; 터미널에서 `ipconfig` 를 입력하면 본인의 내부 네트워크 안에서 사용하는 내부 IP 주소를 확인할 수 있습니다.

~ 주의 ~

&nbsp; `ifconfig.me` 같은 외부 IP 확인 서비스를 사용할 경우 IPv6 주소 공유기인 경우에도 IPv4 주소가 나올 수 있습니다. 이는 ISP가 할당한 공용 IPv4 주소일 수 있습니다. '내 IP 확인' 서비스는 사용자의 요청이 서버에 도달했을 때 서버가 인식하는 발신지 IP 주소를 보여줍니다. 사용자의 컴퓨터가 IPv6 Only 모드이고 내부적으로 고유한 IPv6 주소를 가지고 있더라도, 외부 인터넷으로 나가는 과정에서 NAT64/DNS64 전환 메커니즘을 사용할 수 있습니다. ISP 망의 AFTR(DS-Lite) 또는 CGN 환경을 통해 ISP 측의 IPv4 주소로 전달되어 경유하는 방식일 수 있습니다.

`https://test-ipv6.com/` 를 통해 정확한 데이터를 얻을 수 있습니다.

## 주소가 다를 경우

IPv4 주소 고갈 문제를 해결하기 위해 ISP(LG U+)는 CGN(Carrier-Grade NAT) 방식을 도입했습니다. 이 방식에서는 사용자의 **공유기(Router)**가 ISP의 대형 NAT 장비 뒤에 위치하게 됩니다. 즉, 이중 NAT 환경이 됩니다.따라서 외부에서 사용자의 공유기로 들어오는 접속 시도는 ISP의 NAT 장비에서 차단되거나, 여러 사용자 중 누구에게 전달해야 할지 알 수 없게 됩니다. 이 환경에서는 아무리 사용자 공유기에서 포트 포워딩 설정을 하더라도 실질적으로 외부 접속은 불가능합니다.

이를 확인하는 방법은 컴퓨터에서 확인한 공인 IP 주소와 LG U+ 공유기 관리자 페이지에서 확인한 외부 IP 주소를 비교해 보는 것입니다.

-   두 IP가 같으면: 단일 NAT 환경일 가능성이 높아 포트 포워딩이 작동할 수 있습니다.
-   두 IP가 다르면: 이중 NAT(CGN) 환경이며, 외부 접속은 불가능하다고 보시는 것이 맞습니다.

## (1) IPv6 방화벽 설정

### IPv6 글로벌 유니캐스트 주소 확인

(예시) 내부 컴퓨터의 IPv6 주소가 fe80::... (링크 로컬) 또는 **2406:5900:4000:201:...**와 유사한 글로벌 유니캐스트 주소(GUA) 일 수 있습니다. 외부에서 접근하려면 글로벌 유니캐스트 주소를 사용해야 합니다.

### Windows OS 방화벽 설정 (선택 사항)

내부 컴퓨터에 별도의 방화벽이 있다면 **80번 포트(HTTP)**와 **443번 포트(HTTPS)**에 대한 인바운드 트래픽을 허용해야 합니다.

### 공유기 방화벽 설정

&nbsp; 방화벽/포트 포워딩 메뉴 이동: 설정 메뉴에서 IPv6 방화벽 또는 포트 포워딩(Port Forwarding) 관련 항목을 찾습니다. 보안 설정이나 방화벽 설정 관련된 항목이 있을 확률이 높으며, 아예 메뉴가 보이지 않을 경우 공유기가 방화벽 역할없이 바로 트래픽을 통과시키고 있는 경우도 있습니다.

또는 방화벽 설정이 필요없는 경우도 있습니다.

설정이 끝났다면 IPv6 주소를 대괄호로 감싸서 다음과 같은 형태로 요청을 하면됩니다.

`http://[『IPv6_ADDRESS』]:『PORT_NUMBER』`

예를 들어서 IPv6 주소가 1234:5678:910:112::cd 이고 포트번호가 8080이면 `http://[2406:5900:4000:201::cd]:8080` 입니다. 다만, 포트번호 80은 HTTP 프로토콜의 표준(기본) 포트이기 때문에 URL에 명시적으로 :80을 붙이지 않아도 브라우저가 암묵적으로 (자동으로) 80번 포트로 이해합니다. 포트번호가 80 일 경우엔 `http://[2406:5900:4000:201::cd]` 만 적어도 됩니다.
