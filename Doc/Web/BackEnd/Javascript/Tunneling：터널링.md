# Tunneling：터널링

&nbsp; `TCP` 통신 기반 정적 웹 호스팅 서비스인 GitHub Pages나 Netlify 등은 적합하지 않습니다. `UDP` 통신 기반 게임 서버는 지속적인 연결과 **특정 포트(Port)**를 통한 양방향 통신을 필요로 하기 때문입니다.

&nbsp; AWS에 돈을 들이지 않고 일반 사용자들의 네트워크 제약(`CGN/DS-Lite`로 인한 인바운드 차단)을 우회하여 게임 서버를 외부에 노출할 수 있는 가장 좋은 무료 방법은 터널링(Tunneling) 서비스를 이용하는 것입니다.

&nbsp; 터널링 서비스는 컴퓨터에 설치된 클라이언트 프로그램이 외부의 터널링 서비스 서버와 아웃바운드(Outbound) 연결을 수립합니다. 외부 유저가 이 터널링 서비스의 주소로 접속하면, 해당 트래픽이 ISP의 CGN 방화벽을 우회하여 만들어진 터널을 통해 귀하의 로컬 게임 서버로 전달됩니다.

&nbsp; 무료 터널링 서비스로는 크게 ngrok 과 Cloudflare Tunnel 이 유명합니다.

## ngrok

-   로컬에 설치 후 명령어 하나로 서버 포트(예: $7777$)를 외부 주소에 연결할 수 있습니다.
-   장점: 설정이 매우 간편합니다.
-   단점: ngrok의 무료 티어는 `UDP` 통신을 지원하지 않습니다. 무료 버전은 세션 시간 및 대역폭에 제한이 있으며, 주소가 접속할 때마다 바뀝니다.

## Cloudflare Tunnel (cloudflared)

-   도메인을 Cloudflare에 등록해야 하는 등 초기 설정이 ngrok보다 복잡하지만, 더 강력하고 안정적인 무료 서비스를 제공합니다.
-   장점: 안정적인 연결과 더 관대한 대역폭을 제공하며, 자신이 소유한 도메인을 연결할 수 있습니다.
-   단점: 도메인 등록과 cloudflared 설정을 위한 초기 학습이 필요합니다.
