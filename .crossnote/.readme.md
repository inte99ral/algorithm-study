# Markdown Preview Enhanced

-   게시자 Yiyi Wang

-   vscode 의 미리보기 기능 및 브라우저 출력/pdf 인쇄 기능을 지원합니다.

## 전역에 적용하기

-   `C:\Users\『USER_NICKNAME』\.crossnote` 경로에 해당 설정을 기입하면 전역에 적용됩니다.

## 복수 개의 md 파일 미리보기

```json
{
    // ...
    "markdown-preview-enhanced.previewMode": "Multiple Previews", // <--
    "markdown-preview-enhanced.previewTheme": "none.css",
    "markdown-preview-enhanced.codeBlockTheme": "auto.css",
    "markdown-preview-enhanced.revealjsTheme": "none.css"
    // ...
}
```
